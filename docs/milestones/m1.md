# Milestone 1 acceptance checklist

This milestone is a Go foundation and contract PR. It is complete only when
all items below are true and the diff is reviewed as one stacked PR.

- [x] `go.mod` names `github.com/andrew01234567890/vbdb` and targets installed Go.
- [x] `cmd/vbdbd` strictly parses `--role gateway|metadata|storage` and `--version`.
- [x] `cmd/vbdb-operator` provides an honest dependency-free `--version` scaffold.
- [x] Canonical tuple/component encoding is versioned, deterministic, ordered where promised, and round-trip tested.
- [x] JSON validation rejects duplicate keys, trailing data, invalid UTF-8, unsupported numeric forms, and documents above the 1 MiB bound while preserving integer precision and redacting invalid-input errors.
- [x] Real and manual clocks/timers are injectable and race-safe.
- [x] Named failpoints are explicitly injected and disabled by default; no global hook exists.
- [x] ADRs document API, transactions/OCC, the owned Go LSM/Raft direction, RF3/follower reads, reshard fencing, CDC retention, and backup cut barriers.
- [x] ADRs make durable staged-mutation acknowledgements, failover-exact row
  history, stable retry identities, bearer/CDC separation, bounded transaction
  state, complete encoded CDC-event admission/retention, and unresolved-prepare
  freshness behavior explicit; implementation is reserved for the later
  transaction milestone.
- [x] README, `.gitignore`, Makefile, and GitHub Actions CI provide honest local workflows.
- [x] Public-repository safety gate scans reachable history/ref metadata/index/worktree bytes and intended paths without printing secret contents; its self-test covers replacement refs, grafts, hostile repository-selection environment, credential artifact names, and redacted credential syntax.
- [x] CI checks every committed PR/push patch range with a fail-closed diff-check gate; local worktree checking remains separate.
- [x] Formatting checks derive the repository root, use bounded file batches, fail closed on an empty Go tree, and have an outside-cwd self-test.
- [x] The custom storage engine, Raft, HTTP routes, transactions, CDC, backups, and operator reconciliation remain explicitly later milestones.

Required local gate:

```text
gofmt verification
format self-test
go vet ./...
go test ./...
go test -race ./...
make public-check
make public-check-selftest
make diff-check-selftest
make diff-check
git diff --check
```
