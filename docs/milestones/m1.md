# Milestone 1 acceptance checklist

This milestone is a Go foundation and contract PR. It is complete only when
all items below are true and the diff is reviewed as one stacked PR.

- [x] `go.mod` names `github.com/andrew01234567890/vbdb` and targets installed Go.
- [x] `cmd/vbdbd` strictly parses `--role gateway|metadata|storage` and `--version`.
- [x] `cmd/vbdb-operator` provides an honest dependency-free `--version` scaffold.
- [x] Canonical tuple/component encoding is versioned, deterministic, ordered where promised, and round-trip tested.
- [x] JSON validation rejects duplicate keys, trailing data, invalid UTF-8, unsupported numeric forms, and documents above the 1 MiB bound while preserving integer precision and redacting invalid-input errors.
- [x] Real and manual clocks/timers are injectable and race-safe.
- [x] Named failpoints are explicitly injected and disabled by default; no global hook exists.
- [x] ADRs document API, transactions/OCC, the owned Go LSM/Raft direction, RF3/follower reads, reshard fencing, CDC retention, and backup cut barriers.
- [x] ADRs make durable staged-mutation acknowledgements, failover-exact row
  history, stable retry identities, bearer/CDC separation, bounded transaction
  state, complete encoded CDC-event admission/retention, and unresolved-prepare
  freshness behavior explicit; implementation is reserved for the later
  transaction milestone.
- [x] The stable-retry contract has an executable model for full-result GC and
  restart: durable anti-reuse evidence or a verifiable generation/expiry fence
  survives GC, delayed retries are rejected without mutation, and the selected
  bounded-retention rule is explicit: exhausted anti-reuse admission blocks GC
  and retains complete results; fresh identities are admitted only while the
  complete full-result count/encoded-byte budget fits, then fail closed with
  state unchanged and remain unavailable across restart until a durable
  fence/reclamation transition or capacity change. The model charges one
  exact versioned complete replay-result record (`VBR1`, version `0x01`,
  framed identity/digest, original HTTP status, relevant headers, body,
  envelope, and total-length framing), uses checked subtractive arithmetic,
  and re-accounts after GC/restart; implementation remains a later milestone.
- [x] README, `.gitignore`, Makefile, the CI/workflow ADR, and GitHub Actions provide honest workflows: CI runs Go quality/testing only, while publication-safety and diff checks remain optional local tools.
- [x] The optional local public-repository safety gate scans reachable history/ref metadata/index/worktree bytes and intended paths without printing secret contents; its self-test covers replacement refs, grafts, hostile repository-selection environment, credential artifact names, and redacted credential syntax.
- [x] Optional local diff checks cover the worktree and explicit committed ranges; GitHub Actions does not claim to scan repository history or committed patch ranges.
- [x] Formatting checks derive the repository root, use bounded file batches, fail closed on an empty Go tree, and have an outside-cwd self-test.
- [x] The custom storage engine, Raft, HTTP routes, transactions, CDC, backups, and operator reconciliation remain explicitly later milestones.

Required local quality gate:

```text
make check
git diff --check
```

Optional local publication-safety and diff checks:

```text
make public-check
make public-check-selftest
make diff-check-selftest
make diff-check
make diff-check-ci
git diff --check
```

Before a commit or stack submission, inspect `git diff --cached --stat` and
`git diff --cached`; never publish secrets, private files, or unrelated changes.
